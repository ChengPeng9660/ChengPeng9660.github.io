开始前的小问题

必须购买新的工具吗？

本网站没有账号和网站订阅。试玩示例不调用模型；生成、图片识别使用你自己的 API 账户，并按服务商计费。ChatGPT 等聊天产品订阅不等于 API 余额。

支持整本教材和扫描版吗？

PDF 在浏览器中打开后先选本课页码，读取文字；扫描页可以显式选择用视觉模型识别。支持 TXT、Markdown、JPG、PNG 和 WebP，不支持直接解析 DOCX。每次最多读取 12 页，识别最多 8 张图片，本课最多 24,000 字符。复杂公式、图表、拼音排版请人工核对；不把看不清的图形当作已知条件。

为什么 API Key 正确，也可能无法生成？

服务商必须提供 Chat Completions 兼容接口、开放相应模型权限，并允许浏览器跨域请求（CORS）。本网站不使用公共代理，也不会要求你关闭浏览器安全设置。接口不支持时，可换兼容服务商或使用自己的安全网关。

每篇课文都有完全定制的插画吗？

《棉花姑娘》是完整的定制示例。生成器使用同一套绘本设计语言、可复用的图形和任务组件；它不等于每篇课文都自动制作独立原画与任意新玩法。未知人物采用中性引导图，不把已有动物冒充课文角色。

我的教材和密钥会在哪里？

本网站没有接收教材或密钥的后端，也不主动写入浏览器持久存储。只有你点击生成或识别，所选内容和密钥才发往你确认的 API 服务商；服务商的数据政策另行适用。GitHub Pages 托管会记录访问日志。生成的学生游戏不调用 API。不要上传学生姓名、肖像或不必要的个人资料。
