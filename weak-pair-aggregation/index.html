What the page computes

01

Frozen split

Base questions are split by (source, event_id) with seed 20260913. Every direction of the same base question stays on one side.

02

Learned linear pool

qP = wp1 + (1 − w)p2, with w ∈ [0,1] fitted on the training half.

03

Our log-odds

qL = σ(w logit(p1) + (1 − w) logit(p2)), using the frozen training weight and boundary clip ε = .02.

04

Row-level provenance

The table retains each aligned forecast instance. Scores use direction-aware event identity and event-balanced Brier weighting.
